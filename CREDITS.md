# Credits

## Kode & aset

- Seluruh kode game ditulis khusus untuk proyek ini.
- **Seluruh pixel art (tile, karakter, musuh, efek, font piksel, UI) dibuat lewat kode** di `src/art` dengan palet original
  (`src/art/palette.ts`). Tidak ada aset dari game lain dan tidak ada aset dari Guardian Tales.
- Nama, cerita, dan karakter (Arka — nama di naskah; di game pemain menamai tokohnya sendiri —, Nara, Tetua Wulan,
  Kolosus Kelam, Ravenhollow, Hutan Noctis, dll.) adalah original.
- **Musik, suasana, dan efek suara disintesis** lewat WebAudio (`src/core/audio`), tanpa berkas audio.
